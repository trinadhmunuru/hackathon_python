# ICODIP - Compliance & Intelligence System

ICODIP is a robust backend system built with **FastAPI** and **MySQL** to manage workflows, intelligence analysis, and real-time monitoring.

## 🚀 Features
The system consists of 10 specialized endpoints categorized into:
- **Workflow Management**: Trigger, process, and complete business workflows.
- **Intelligence Analysis**: AI-based risk scoring, high-risk detection, and flagging.
- **Real-time Monitoring**: System heartbeat, audit logs, and alert resets.
- **Admin Tools**: Secure record deletion from MySQL.

## 🛠️ Tech Stack
- **Framework**: FastAPI
- **Database**: MySQL
- **ORM**: SQLAlchemy
- **Language**: Python 3.10+
